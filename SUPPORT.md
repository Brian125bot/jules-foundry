# Support

Jules Foundry technical-preview support is best-effort through the [GitHub issue tracker](https://github.com/Brian125bot/jules-foundry/issues). Before opening an issue, review the [local run guide](docs/LOCAL_RUN_GUIDE.md), [release readiness](docs/RELEASE_READINESS.md), [Linux technical-preview feedback template](docs/TECHNICAL_PREVIEW_FEEDBACK_TRIAGE.md), and the current release notes.

Do not post provider tokens, one-time bootstrap URLs, local databases, backups, or sensitive repository contents in a public issue. Use the private path in [SECURITY.md](SECURITY.md) for suspected vulnerabilities.
